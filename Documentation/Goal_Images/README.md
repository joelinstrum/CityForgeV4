# CityForge V4 goal images

These ten world concept images are visual references for the V4 build. They show a possible progression from an inhabited landscape through later riverfront cities. The files are preserved at their original 1536 × 1024 resolution. [Overview](Overview.jpg) is a smaller contact sheet for browsing; use the individual PNGs for detailed comparison. The [opening menu concept](MenuPageConcept.png) is a separate UI target.

![Contact sheet of ten CityForge V4 concept images](Overview.jpg)

## How to use them

Compare a running Unity screenshot with a relevant image at a similar camera angle and scale. Identify specific visible gaps in terrain form, water, shoreline transitions, vegetation, material response, lighting, architecture, or city density. Use those observations to guide a prototype and review the result in the game. The images are visual targets, not literal asset lists, final gameplay designs, or proof that any rendering technique will work.

These images also are **not historical reference material**. Architecture, dress, settlement form, and place names need independent research before becoming factual game content. The image of an Indigenous village should inform the principle that the landscape can contain people and places before the player's city; it does not depict or validate a specific nation, settlement, or historical event.

## First prototype comparison

Start with images **01** and **02** for landform, river depth, banks, vegetation, and lighting. Image **04** can test the first building and road against that landscape. Use **06–10** later to test whether the rendering approach still works when the region is dense. The exact prototype scope and acceptance thresholds remain open; the images provide a common visual reference for those decisions.
