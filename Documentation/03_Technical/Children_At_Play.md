Source FBX/textures, prepared materials/controllers/prefabs and reduced meshes remain local/ignored under Resources/Lots/V3Characters/Child*.

Schoolyard hours are09:00 inclusive to15:00 exclusive, using the district clock. Outside those hours the model hierarchy is inactive while the schedule driver remains active; at09:00 the same children reappear in place. Hidden children do not advance their action/idle counters. The Lot Editor keeps them visible/selectable for authoring at all preview times. `CharacterScriptHours` centralizes per-behavior defaults, with all-day and overnight-range support; only Children at play is restricted so far. Schedule editing and new persisted time fields are deferred.

Newly placed children default to **Children at play**. The same option is available under Character Script → Scripted. Explicitly choosing Randomized retains the existing configurable character behavior. Children at play runs their own available Idle/Walk/Cheer, Idle/Walk/Clap/Jump, Idle/Walk/FoldArms or Idle/Walk/LookAround states. Walk is in place: root motion is disabled and the script never changes the placed transform. No new animations or roaming routes are invented.

The scheduler starts idle, randomly selects an available action, then idles before the next action. Actions last at most8 seconds and cannot consume more accumulated non-idle time than the child has earned in idle time. Extra idle time covers transitions. This guarantees at least50% idle cumulatively, rather than merely giving idle a50% random probability. A deterministic per-instance random stream avoids changing Unity's global random state. Children pause while the district loads or saves; the Lot Editor drives the same behavior manually for previews. No transient animation counters are written to player saves.

ChildrenAtPlay is appended as enum value7; existing scripted behavior values0–6 are preserved. The existing characterScript field persists the explicit choice, and unconfigured child asset IDs retain the default behavior on reload. Direct district children use their own presentation root so they do not join pedestrian street circuits. The existing DistrictPlacedActor record stores their IDs/positions, without a new save schema.
