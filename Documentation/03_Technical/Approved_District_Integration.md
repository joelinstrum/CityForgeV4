# Approved district presentation integration

October 30, 2026. Local implementation; validation results are recorded separately below.

## Normal entry

The relief overview remains lightweight. Every selected district, including recipe-less legacy saves such as Meadow Test Valley, now enters `MeadowDistrictLandscape` through the existing preloader. The historical district-3-only gate is removed. Native trees start enabled regardless of the hidden study preference; the explicit runtime toggle still works. ## Authored summer forest

`ApprovedDistrictForest` reads locally generated `ApprovedForestAssets` from Resources. The source-only builder verifies the immutable refined-C checkpoint using its existing verifier before generating private Unity mesh/material assets. All 35 accepted meshes are indexed/deduplicated using the same replay procedure. Mesh shape, crown spread, scale recipe, palette and leaf coverage texture are preserved. District placement reuses the accepted 400-core/150-edge/50-outlier layout quotas, applies road/water/native-tree/slope exclusions, and additionally respects generated woodland ecology. It adds presentation instances without modifying native serialized placements.

Visible and coarser shadow meshes render in instanced batches without per-tree GameObjects or the study's 6,000 shadow-proxy GameObjects. This runtime renderer uses discrete authored LODs; it does not yet reproduce the study's crossfade transitions. No global render-scale or VSync settings are changed. Sustained final-shader performance still needs qualification.

Baseline native summer foliage uses private prefab/material clones with the accepted pale-tree tint on near and cross/billboard materials. Original materials and seasonal assets are untouched. Grass layers 1/2 use checkpoint derivatives on district-owned cloned layers. The approved authored family has only a summer baseline: native fall/winter trees remain authoritative and the supplemental summer canopy is hidden in those seasons. Authored seasonal variants require separate work and approval.

## Water

River-only legacy and generated districts build their bounded river reference, then automatically initialize the native Crest grid and accepted selective/evolving glints. The accepted normal scale/strength, blue/teal base, 0.55 m/s current, evolution amplitude 0.018/speed 2 and high-tilt restraint are retained. No inspection-camera movement, wildlife toggles or editor menu are part of deployment. The stationary terrain wet/dry clip and eight-cascade coverage are reused. Legacy saves use their canonical river centerline widths as well as terrain height for the wet mask: their water-distance field is unsigned and broad low meadow must remain dry.

Districts intersecting saved ocean descriptors use the established coastal Crest wave/foam presentation, with wet clipping sampled from their saved terrain. Surf follows the stored ocean outline rather than assuming the special coastline test's west-facing shore. The original coastline-test code path remains. Districts containing both ocean and river currently share the coastal water engine/material; an independently shaded estuary transition remains unfinished. The region wizard still does not generate ocean geography.

## Private asset preparation

In Edit mode, use `CityForge/Forest/Build approved runtime assets` once. This verifies `SourceAssets/ApprovedForest/RefinedC-2026-10-28/` and writes ignored `Assets/CityForge/Resources/ApprovedForest/`. The builder refuses an existing output folder, preserving it for review instead of overwriting it.

The accepted local generated river shader must already exist. Rebuild it via `Library/RiverGlintShader.request` when needed, then use `CityForge/Water/Prepare approved runtime river shader` to copy it into ignored Resources and bake a configured river material for player inclusion. The actual material retains transparency, alpha-clipping, flow and specular shader-feature variants; loading only the shader and changing keywords at runtime is insufficient in a stripped player build. The forest builder also prepares it. The forest build also bakes four private terrain-material keyword combinations (`_NORMALMAP` / `_MASKMAP`) via `Prepare runtime terrain variants`. These materials retain runtime Terrain variants in stripped players; the original terrain material, mask data and lighting remain unchanged. Without retention the player substitutes default mask channels, creating strong ground specular glare that contaminates river refraction. Neither licensed/generated shaders nor forest meshes/textures/materials/prefabs belong in public Git. Missing resources produce a clear loading error, not retired-art fallback.

After reviewing the integrated scene against the photographic goals, the user requested approximately 25% lighter authored crowns and rivers that separate clearly from grass. ## Panning cadence and batch uploads — October 30

The user clarified that zoom3/4 jaggedness meant uneven motion, not edge aliasing. At 3434×1818 on the 120 Hz display, player measurements showed mixed frame intervals at zoom3 and a much faster cadence at zoom4. The hardware VSync profile now selects the supported divisor (1–4) closest to 60 Hz; this uses divisor2 at 120 Hz and divisor1 at 60 Hz. It refreshes when the display refresh rate changes, preserves the uncapped toggle, and restores the previous settings on leaving the meadow. No software frame limiter or anti-aliasing change was introduced. Frozen checkpoint replay retains its previous divisor1 behavior.

The authored renderer now groups by mesh/LOD rather than splitting the same mesh into three palette draws: 35 possible groups instead of 105. Palette/tint remains per-instance shader data. Probe uploads use actual instance count rather than 1,023 entries per draw, and per-variant capacities are allocated before navigation. Tree positions, meshes, LOD thresholds, colors, lighting and the existing temporary navigation-quality reduction are unchanged. Final player timing evidence is in the chat's pan-review outputs. This is a focused navigation check, not a city-scale performance guarantee.

### Local panning density fixtures
`PanningTestDistricts` recognizes four explicit diagnostic save IDs only. It uses a fixed xorshift/Fisher-Yates ordering and nested masks to retain 0/30/50/80 percent of each canonical presentation population. Native filtering selects mature canonical instances before species presentation and does not alter `CanonicalTreeInstances`; enabled small plants are appended separately so mature tree placement stays fixed; authored filtering happens after placement/exclusion generation. The zero-tree authored path exits before culling and batch work. Normal save IDs retain the existing full presentation. Four local fixtures have byte-identical terrain/paint/tree payloads with waterless metadata; original valley remains untouched. At the current native species preferences, visible native/authored counts are 0/0, 621/180, 1035/300, and 1656/480. Keep species and seasons fixed for comparisons; changing presentation preferences can change the native denominator. Automatic district entry applies only to these diagnostic IDs.

Coastal test `pan-test-coast-50` is also recognized at 50%. It now opens with small plants enabled and animals enabled in its local save. The other density fixtures retain small plants off by default. Two standalone comparison passes found higher slow-frame rates with vegetation and wildlife combined; see the current chat comparison report for raw frame times, condition order, and measurement limitations. No performance tuning was applied during that comparison.

### Navigation work suspension
`CameraMotionQuality.NavigationWorkSuspended` follows the existing motion/settle quality interval. Only runtime streamed ground cover opts into it: tile generation/eviction/queue updates pause, and tile renderers skip submission while preserving caches. Full terrain instance arrays are never rewritten on pan. Settling resumes existing budgeted tile processing. The component executes before ground-cover LateUpdate so vegetation drawing is suppressed in the same motion frame. Disabling the component restores render scale/LOD and clears its suspension state. Trees keep the existing global motion LOD reduction; water and wildlife remain active. Experimental animal pausing was removed after a standalone comparison showed no convincing incremental advantage over vegetation suspension.
