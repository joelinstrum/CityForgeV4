# Lot Editor Characters Gallery

Characters uses the same responsive 1640 × 900 gallery frame as Buildings, Trees, Fences and Landscaping. It lists the existing private Characters catalog; no new characters are created from the reference artwork.

The era filter always includes every configured CityForge timeline era in timeline order, including eras without character assets. Empty eras show an explicit not-yet-available message and disable selection. Additional unmatched catalog group labels remain accessible after the configured eras.

Controls include catalog-era filtering, name/search/history sorting, favorites, recent filters, grid/list views, thumbnail sizing and pagination. The two existing Founders Era spelling variants share one displayed era without modifying catalog data. These are catalog labels, not newly inferred historical availability dates.

Single-click updates details and preserves the card for native double-click detection. Double-click or Select Character delegates to the original ArmAsset placement flow. Character sizing, snapping, animation scripts and save schemas remain unchanged. The modal omits building properties, wealth, footprint sorting and placement size variation. Browsing does not mutate the lot. Player-mode cosmetic restrictions remain authoritative; Characters remains an authoring category.

Previews use actual native models with shared daylight lighting, rotation and expansion. Favorites and used IDs persist separately at CityForge.Characters.Favorites and CityForge.Characters.Used; recent IDs use the existing recent history.

User-supplied private art lives in Resources/UI/LotCharacterGallery/Portrait.png and Harbor.png and remains ignored by the public source-only repository.
