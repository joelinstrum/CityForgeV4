# Downloaded maple trial retired — October24, 2026

The user decided the imported maples did not suit the intended forest appearance and requested their removal before committing the branch.

The original import, close-quality, population, opaque-cluster and leafy-branch variants were optional uncommitted previews. They were never added to the production seasonal tree library or canonical saved tree placements. Their editor request handlers, menu commands, runtime controls/billboards, custom foliage shaders and rebuilding scripts have been removed from the active project. Stopping the unsaved Play-mode fixture removed the live trial objects and restored its temporary rendering overrides.

All local trial artwork now resides outside Unity's Assets directory in ignored `SourceAssets/MapleTrial/RetiredRuntimeAssets-2026-10-24`. Original supplied models/textures remain in `SourceAssets/MapleTrial`. Detailed experimental source and notes are recoverably archived outside the project in the October22 chat workspace's `work/maple-trial-retired-2026-10-24` directory. Neither licensed artwork nor this archive belongs in the public repository.

The approved native meadow/poplar biome and pre-existing Silver Maple species remain the baseline. Camera controls, water, seasonal assets, species preferences and player saves are unchanged. Do not reintroduce the downloaded candidates as a fallback.

The evaluations established that distant baked trees were inexpensive, while the initial detailed leaf meshes were prohibitively costly at forest density. Aggressive reductions improved performance but not the desired appearance. Opaque lobe and regrouped leafy approaches were rejected. Those findings are historical asset-evaluation results, not production features or performance guarantees.
